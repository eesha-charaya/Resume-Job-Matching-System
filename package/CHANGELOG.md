# Changelog

All notable changes to the Python package are documented here.

## [0.2.0] - 2026-11-02

### Added
- Structured degree, seniority, and years-of-experience extraction
- Metadata filter construction for retrieval systems
- Command-line interface with `clean`, `extract`, and `metrics` commands
- Typed package marker (`py.typed`)
- Tests for extraction, filtering, and CLI behavior
- Coverage, lint, type-check, build, and distribution validation in CI
- Expanded package documentation and examples

### Changed
- Expanded the public package API
- Raised package version from 0.1.0 to 0.2.0

## [0.1.0] - 2026-11-02

### Added
- Installable package metadata with `pyproject.toml`
- Job-description preprocessing utilities
- Precision@k and recall@k retrieval metrics
- Initial pytest suite
